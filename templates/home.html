AD Attack Lab

Acasa Atacuri Free Lab Setari

Infrastructura virtuala pentru simularea si monitorizarea atacurilor in Active Directory

Platforma demonstreaza cum misconfiguratiile clasice din infrastructuri Active Directory (Windows Server 2019) pot fi exploatate prin tehnici cunoscute de atac. Atacurile abuzeaza functionalitati legitime ale protocoalelor Windows configurate gresit, scenarii frecvente in medii enterprise reale.

Atacuri simulate
AS-REP Roasting (T1558.004)
Kerberoasting (T1558.003)
Password Spraying (T1110.003)
DCSync (T1003.006)
Pass-the-Hash (T1550.002)
Stack tehnic
Flask + SocketIO (WSL)
Kali Linux — impacket, netexec
Windows Server 2019 — Active Directory
Ubuntu — Wazuh SIEM
Arhitectura
  [Browser]
      ↕ WebSocket (live output)
  [Flask pe WSL]
      ↓ SSH
  [Kali Linux VM — 10.10.128.4]
      ↓ atacuri AD (impacket, netexec)
  [Windows Server 2019 — DC01 — 10.10.128.2]
      ↓ Windows Event Logs → Wazuh Agent
  [Ubuntu VM — Wazuh Manager — 10.10.128.3]
      ↑ SSH (alerts.json)
  [Flask pe WSL]  →  [Browser — sectiunea Detection]
Setup Lab
Pasul 1
Cerinte hardware si software
  • PC / Laptop — minim 8 GB RAM, 100 GB storage liber
  • VMware Workstation Pro 17.6.2 (sau versiune mai noua)
  • WSL2 pe Windows host — pentru rularea aplicatiei Flask
Pasul 2
VMware — Retea virtuala (VMnet8)

Toate cele 3 VM-uri trebuie sa fie in aceeasi subretea. Se creeaza o retea de tip NAT in VMware Workstation → Virtual Network Editor, numita VMnet8, cu DHCP dezactivat. 

Subnet IP:   10.10.0.0
Subnet Mask: 255.255.0.0
Tip:         NAT (VMnet8)
DHCP:        Dezactivat

IP-uri statice setate pe fiecare VM (Network Adapter → NAT):

VM                    IP             Masca           Gateway
Windows Server DC01   10.10.128.2    255.255.0.0     10.10.1.250
Ubuntu / Wazuh        10.10.128.3    255.255.0.0     10.10.1.250
Kali Linux            10.10.128.4    255.255.0.0     10.10.1.250

! Activeaza primirea pachetelor ICMP in Windows Firewall pentru a testa comunicarea intre VM-uri (ping).

Tutorial extern: Creare Retea Virtuala VMware
Pasul 3
Windows Server 2019 — Active Directory

Descarca ISO-ul evaluat gratuit de la Microsoft Evaluation Center si instaleaza Active Directory Domain Services. Promoveaza serverul ca Domain Controller. Conecteaza-l la VMnet8 si seteaza IP static la 10.10.128.2.

Configurare domeniu

Server hostname:  DC01
Domain (FQDN):    corp.local

Organizational Units si utilizatori

Corp_Users
    andrei.popescu    kk123456$
    mihai.popa        kk12345$
    ion.alexa         kk12345$
    emilia.lucescu    kk12345$
    diana.petrescu    kk12345$
Corp_IT
    it.admin          kkk12345$
    it.support        kkk12345$
Corp_ServiceAccounts
    svc.backup        kkkk12345$
    svc.web           kkkk12345$

Utilizatorii normali nu pot face login pe Domain Controller (buna practica de securitate).

Misconfigurationi necesare pentru atacuri

# AS-REP Roasting — dezactiveaza preauth pe conturile de serviciu
Set-ADAccountControl -Identity "svc.backup" -DoesNotRequirePreAuth $true
Set-ADAccountControl -Identity "svc.web"    -DoesNotRequirePreAuth $true

# Kerberoasting — inregistreaza SPNs
setspn -a HTTP/svc.web       corp\svc.web
setspn -a backup/svc.backup  corp\svc.backup

# Password Spray — dezactiveaza lockout (doar pentru laborator!)
# Group Policy Management → Default Domain Policy →
# Account Policies → Account Lockout Policy → Threshold: 0

# DCSync — adauga it.admin in Domain Admins (drepturi de replicare)
Add-ADGroupMember -Identity "Domain Admins" -Members "it.admin"

Audit Logging (necesar pentru detectia Wazuh)

auditpol /set /subcategory:"Process Creation"        /success:enable /failure:enable
auditpol /set /subcategory:"Directory Service Changes" /success:enable /failure:enable
auditpol /set /subcategory:"Credential Validation"     /success:enable /failure:enable

Pasul 4
Kali Linux

Descarca Kali Linux (VMware edition) de la kali.org/get-kali. Importeaza VM-ul in VMware, conecteaza-l la VMnet8 si seteaza IP static la 10.10.128.4.

Activare SSH (obligatoriu — platforma comunica cu Kali prin SSH)

sudo apt update
sudo apt install openssh-server -y
sudo systemctl enable ssh
sudo systemctl start ssh
sudo systemctl status ssh   # verifica ca e active (running)
Tutorial extern: Instalare Kali Linux pe VMware
Pasul 5
Ubuntu 24.04 + Wazuh

Descarca Ubuntu 24.04 LTS si creeaza o VM noua in VMware, conectata la VMnet8. Seteaza IP static la 10.10.128.3. Instaleaza Wazuh all-in-one (manager + indexer + dashboard) cu scriptul oficial.

Instalare Wazuh

curl -sO https://packages.wazuh.com/4.14/wazuh-install.sh
sudo bash ./wazuh-install.sh -a

Dupa instalare: dashboard disponibil la https://10.10.128.3 (user: admin, parola generata la instalare)

Activare automata la reboot

sudo systemctl enable wazuh-manager
sudo systemctl enable wazuh-indexer
sudo systemctl enable wazuh-dashboard

Instalare Wazuh Agent pe Windows DC01

In dashboard-ul Wazuh → Agents → Add agent → selecteaza Windows → copiaza comanda PowerShell generata si ruleaz-o pe DC01. Agentul porneste si se conecteaza automat la manager.

In caz de probleme: sudo systemctl restart wazuh-manager

Tutoriale externe: Instalare Ubuntu Instalare Wazuh + Agent pe Windows Wazuh Quickstart (documentatie oficiala)
Pasul 6
Snapshots si rulare aplicatie

Dupa ce ai configurat toate VM-urile cu misconfiguratiile de mai sus, fa un snapshot curat pe fiecare. Platforma poate reveni la el automat in caz de erori. 

Kali:    snapshot → "default-kali-clean"
Windows: snapshot → "AD-configured-clean"
Ubuntu:  snapshot → "ubuntu-wazuh-clean"

Prima instalare (o singura data)

cd /path/to/licenta-infras_attack
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

Rulare (de fiecare data)

source venv/bin/activate
python app.py

# Acces: http://127.0.0.1:5000
